# pch4_genetic_lactation
Stage-resolved host genetic regulation of predicted methane production across lactation in Holstein cattle

## Additional file 1: Supplementary Tables S1–S10
File format: Microsoft Excel workbook (.xlsx).
Title: Supplementary data for stage-specific genetic and regulatory analyses of predicted methane production.
Description: This workbook contains ten worksheets corresponding to Supplementary Tables S1–S10 cited in the main text. The tables provide tissue sample sizes, stage-specific association results, functional enrichment results, integrated evidence for candidate genes, and SNP–gene–tissue–stage evidence chains.

Table S4. GO and KEGG enrichment results for GWAS-annotated candidate genes.
Table S5. Significant gene–tissue–stage associations identified by TWAS.
Table S6. Colocalized gene–tissue–stage associations with PP.H4 ≥ 0.80.
Table S7. Gene–tissue–stage associations with nominally significant weighted-median Mendelian randomization results.
Table S8. High-confidence candidate genes and gene–tissue–stage associations supported by at least two methods.
Table S9. GO and KEGG enrichment results for high-confidence candidate genes.
Table S10. Integrated SNP–gene–tissue–stage evidence chains and supporting association evidence.


## Additional file 2: Regional association plots of GWAS–cis-eQTL colocalization signals for PCH4 across lactation stages.
File format: PDF (.pdf).
Regional association plots for gene–tissue–stage combinations identified through colocalization analysis. The upper and middle panels show GWAS and cis-eQTL association signals, respectively, within 1 Mb upstream and downstream of the transcription start site of each candidate gene. GWAS associations are displayed using genomic-control-corrected P-values, whereas cis-eQTL associations are represented by nominal P-values obtained from FastQTL. Shared SNPs with available linkage disequilibrium estimates are colored according to their LD (r²) with the reference SNP, calculated using the CattleGTEx reference panel. Other variants are shown in gray. The vertical dashed line indicates the LD reference SNP, and the lower panel shows the genomic position of the target gene. Colocalization evidence is summarized by the posterior probability of a shared causal variant (PP.H4).
